# The Void Harbinger (Вестник Пустоты) — Fabric 1.20.1

Мод на опасного эндгейм-босса с 3D-моделью, покадровыми анимациями **GeckoLib 4**, трехфазным боем и легендарным дропом.

## Быстрая сборка (в 1 клик на Windows):
1. Распакуйте архив в любую папку.
2. Запустите двойным кликом файл **`BUILD_MOD.bat`**.
3. Gradle автоматически загрузит маппинги Fabric 1.20.1, скомпилирует исходный код в байткод `.class` и создаст готовый файл **`void_harbinger-1.0.0-READY.jar`**.
4. Поместите `void_harbinger-1.0.0-READY.jar` в папку `mods` вашего экземпляра PrismLauncher.

*(Для сборки через терминал: `gradlew build` или `./gradlew build`).*

## Зависимости (уже присутствуют в вашем PrismLauncher):
- Fabric Loader 1.20.1
- Fabric API 1.20.1
- GeckoLib 4 (версии 4.2+)
